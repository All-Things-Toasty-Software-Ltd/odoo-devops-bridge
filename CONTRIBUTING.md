# Contributing

Thank you for your interest in contributing to this project.

## Before contributing

Before starting work, please check the existing issues and merge requests to see whether the work
has already been discussed.

For significant changes, opening an issue before beginning development is recommended.

## Development

Project-specific development instructions are documented in the project README or development
documentation.

Please follow the existing structure, conventions, and tooling used by the project.

Keep changes focused and avoid unrelated modifications.

## Commits

Write clear commit messages that describe the purpose of the change.

Do not commit:

* Passwords
* API keys
* Access tokens
* Private keys
* Credentials
* Personal data
* Unnecessary generated files

## Merge requests

Merge requests should:

* Clearly describe the changes being made.
* Explain how the changes were tested.
* Reference related issues where applicable.
* Include relevant documentation changes.
* Contain only changes relevant to the purpose of the merge request.

## Testing

Changes should be tested appropriately before being submitted.

New functionality should include tests where practical.

## Documentation

Update documentation when behaviour, configuration, installation, or usage changes.

## Licensing

Contributions to this project are subject to the project's applicable licence.

If you are unsure whether you can contribute particular code, assets, or other material, check their
licensing before submitting them.

## Questions

If you are unsure about something, open an issue or contact the project maintainers before making a
substantial change.
